Account & Data Deletion

This page explains how to request deletion of data associated with Shinng’s optional sign-in, backup, and restore features.

Last updated: April 30, 2026

Contents

How to Request Deletion

To request deletion of Shinng account-linked or backup-related data, send an email with the details below.

  • Send the request to bawender.y@gmail.com.
  • Use the subject line Data Deletion Request - Shinng.
  • Include the Google account email used in the app, if you used Google Sign-In for backup or restore.

What Data Will Be Deleted

If matching data is found, Shinng will delete app-linked data associated with your sign-in, backup, or restore usage.

  • Optional cloud backup data associated with Shinng
  • User backup records stored in cloud storage, if used
  • Any associated app-linked data tied to the backup account

Data Storage Clarification

Shinng does not require account creation for core expense tracking. Most expense data is stored locally on your device.

Shinng does not store your personal financial data on its own external servers. Optional sign-in is used only for backup and restore functionality.

To remove local data from your device, clear Shinng’s app data from system settings or uninstall the app.

Retention Timeline

Deletion requests are processed within 7 days after we receive the required account information. We may reply to confirm details if the request cannot be matched to account-linked or backup data.
